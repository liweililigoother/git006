网页GAME：高级感空中投弹开发方案本项目旨在打造一个高画质、强表现力的网页版空中投弹游戏。通过毛玻璃 UI 与极致的爆炸动效，结合反重力的幽默元素，创造出一种“华丽且不正经”的竞技体验。一、 核心视觉与感官逻辑1. 动态背景与场景 (High-Fidelity Environments)游戏将提供四种视觉风格迥异的超高清动态场景：亚洲热带森林：翠绿欲滴的植被，伴随夸张的彩色雾气。非洲沙漠：滚烫的热浪视觉扭曲（Heat Haze），偶尔漂过巨大的仙人掌气球。南美高山峡谷：深不见底的裂谷，云朵像棉花糖一样可以被炸碎。北大西洋深海：幽暗的深蓝色，巨大的发光水母作为背景装饰，投下的炸弹会产生气泡轨迹。2. 局部强动画与爆炸特效 (VFX & Animation)强爆炸效果：投弹击中目标时，触发多层粒子系统——火焰、烟雾、四溅的Q版零件，并伴随屏幕剧烈抖动（Screen Shake）。反重力表现：物体被炸飞后会在空中缓慢旋转、甚至向上飘走，强调“怡乐”感。视觉风格：保留 GAME001 的毛玻璃容器（用于 UI 面板）和深色海洋蓝作为 UI 底色，但游戏画面本身采用高饱和度的鲜艳色彩。3. 音效表现 (Audio Experience)重怡乐风格：爆炸声不一定是轰鸣，可以是“砰”、“啾”或者搞怪的人声配音。动态音轨：随着血量降低，背景音乐（BGM）的速度会加快并变得鬼畜。二、 交互与核心玩法1. 操作模式 (Mouse Control)鼠标为主：移动鼠标控制飞机位置或瞄准准星。左键/右键：分别对应不同类型的弹药（例如：常规炸弹 vs 搞怪烟花弹）。模糊提示：抛物线轨迹仅做半透明的淡影提示，增加操作的直觉性而非精确性。2. 数值与反馈血量系统：初始血量 100。关键特效：【重要的事情说三遍】：当血量跌至 10 时，屏幕中央会触发强烈的视觉冲击，文字以红紫色闪烁效果连弹三次，配合鬼畜音效，提醒玩家进入濒死状态。难度设定：设有一个基础难度系数 $D = 100$。提供三级难度预设：简单、普通、疯狂。后期将开放参数接口，方便你手动调节障碍物速度和目标体积。三、 功能模块设计用户与数据系统：毛玻璃登录面板：延续高级感设计，记录玩家登录频次。战绩排行榜：记录最高分、生存时间、以及“炸毁物体总数”。后端支撑：使用 Supabase 实时存储玩家的每一局得分。记录用户登录时间戳，生成个人游戏周报。四、 开发实施步骤阶段一：场景渲染器利用 WebGL 或高性能 Canvas 框架实现四个高画质场景的循环滚动。加入 CSS3 滤镜实现毛玻璃 UI 层。阶段二：投弹物理引擎（反重力版）开发基于鼠标点击的发射逻辑。编写“不正经”的物理反馈（如物体被击中后变大缩小、乱飞）。阶段三：特效与音效库集成粒子库（如 PixiJS 或 THREE.js 粒子系统）制作强爆炸效果。植入“重要的事情说三遍”特定触发动效。阶段四：后端对接与难度调优接入登录接口与分数上报。开放难度值调节接口，供后期测试微调。

细节方案：老飞机的机械浪漫一、 核心操作：飞机控制 (Aircraft Handling)同步位移：飞机的 X 轴坐标直接绑定鼠标的 X 轴。鼠标移动越快，飞机左右倾斜的幅度越大（带有惯性补偿的平滑移动），增加飞行的肉感。视觉细节：飞机机翼在高速移动时会轻微抖动，排气管喷出带有像素微粒的黑烟，与高画质的背景形成鲜明对比。二、 机械感物理反馈 (Physical Feedback)既然以声音和机械感为主，我们将通过以下方式强化体验：1. 环境音效 (Spatial Audio)机翼风噪：飞机左右快速摆动时，左右声道会交替出现“呜呜”的风切声。机械摩擦：随机触发老飞机特有的金属扭曲声（Creal-Squeak），让玩家感觉这台机器随时可能散架，增加紧张感。碰撞反馈：飞鸟：如果撞到飞鸟，屏幕会溅上一朵羽毛特效，并伴随“嘎”的一声惨叫和机身的剧烈一震。气流：经过云团时，音效变厚重，飞机产生随机的微小颠簸。2. 反重力爆炸 (Anti-Gravity VFX)投弹动作：鼠标左键投弹，右键释放“搞怪特殊弹”。爆炸逻辑：炸弹触地后，目标不是被炸碎消失，而是伴随着巨大的“砰”声，像断了线的气球一样，晃晃悠悠地向天空飘去。搞笑元素：被炸飞的敌人可能会一边升空一边发出“我还会回来的”之类的滑稽配音。三、 “重要的事情说三遍” (Critical Visuals)当血量降至 10 时，进入濒死幽默模式：第一遍：屏幕剧烈抖动，正中央弹出巨大的“注意：要掉下去了！”第二遍：背景音乐瞬间切为 2 倍速的鬼畜版，再次弹出“注意：真的要掉下去了！！”第三遍：飞机机翼掉落一个零件，弹出“注意：说三遍了，真没救了！！！”画面表现：此时整个毛玻璃 UI 会变成警示红色，但文字依然保持那种“不科学”的幽默感。四、 后端与难度调节基础难度 $D=100$：Level 1 (安逸)：风阻小，飞鸟少，炸弹飞行速度快。Level 2 (颠簸)：机翼异响频率增加，开始出现侧向干扰气流。Level 3 (疯狂)：反重力现象频发，屏幕到处是乱飞的零件和惊恐的鸟群。
