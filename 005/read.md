


# 任务：为 A 股 688027（国盾量子）搭建定制化特征点监控与回测工作站

## 1. 环境与数据接入 (Data Connector)
- **技术要求**：Python 3.10+，使用 Streamlit 框架构建 UI。
- **数据源小贴士**：请务必使用 `akshare` 库获取数据。它开源且无需积分，直接在环境中 `pip install akshare`。
- **抓取逻辑**：获取 688027.SH 过去 40 个交易日的数据，重点提取每日 **09:15 - 10:00** 的分钟级 L2/分时数据。

## 2. 核心特征算法 (Feature Engineering)
实现以下三个量化指标：
- **竞价强弱度**：计算 (今日 09:25 成交额 / 过去 40 日竞价成交额均值)。
- **10点前效率**：计算 (10:00 时价格相对开盘价的变动 / 10:00 前的累计成交量)。
- **护城河支撑检测**：定义 578-580 为“黄金坑”区间，实时监测价格进入该区间时的买盘挂单厚度，识别“特征拐点”（即放量不跌的瞬间）。

## 3. 实时图形化仪表盘 (Strategic Dashboard)
- **核心组件 (汽车仪表盘)**：使用 `plotly.graph_objects` 中的 `Indicator` 组件实现。
    - **显示内容**：今日回抽目标位（592.00）的概率预测。
    - **逻辑**：基于当前 10 点前的量价比与历史成功回抽样本的匹配度。
- **动态压力带**：在 UI 中实时绘制一条基于成本价（579.00）的水平带。
    - **颜色预警**：价格在 579 之上且买盘强劲时显示“绿色护城河”；跌破则显示为红色警告。

## 4. 高级相似度分析 (Pattern Matching)
- **算法小贴士**：引入 **DTW (Dynamic Time Warping, 动态时间规整)** 算法。
- **功能**：对比今日 09:15-10:00 的走势曲线与过去 40 天中每一天的形态。识别出形态最相似的“历史孪生日”，并在热力图中展示其后续走势，辅助判断今日回抽空间。

## 5. 仿真测试 (Simulation)
- 提供一个 Mock Data 函数，能够模拟 09:15 至 10:00 的价格跳动，以便在 IDX 环境中直接预览仪表盘的动态反馈。
